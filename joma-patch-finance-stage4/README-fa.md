# راهنمای نصب پچ «فاز ۵ — فروشِ تست‌ها و پکیج‌ها» (مرحلهٔ ۴)

این پچ **بخش چهارم** ماژول مدیریت مالی را اضافه می‌کند:

- 🧪 **فروشِ تست‌ها** — ثبتِ فروشِ تست (مراجع، نامِ تست، مبلغ، حسابِ بانکی
- 📦 **فروشِ پکیج‌های تمرینیِ یک‌ماهه** — ثبتِ فروش + بازهٔ اعتبارِ یک‌ماهه
  (تمرین‌ها خارج از سیستم انجام می‌شوند — PDF/لینک)
- 💰 **وضعیتِ پرداخت** برای هر فروش: «در انتظارِ پرداخت» 🟡 / «پرداخت‌شده» 🟢
  (تاریخِ پرداخت خودکار ثبت می‌شود)
- 🏦 **حسابِ بانکی** — «حسابِ بانکیِ پرداخت» در لحظهٔ ثبت/ویرایش از فهرستِ کشویی انتخاب می‌شود
- 📅 **تاریخ‌ها بدون تایپ** — بازهٔ اعتبار با انتخابگرِ سه‌بخشیِ
  **سال / ماه / روز** وارد می‌شود (پیش‌فرض: از امروز تا یک‌ماهه بعد)
- 👥 هر دو نقش **مدیر و منشی** به این صفحات دسترسی دارند

> ⚠️ **پیش‌نیاز:** مراحل ۱ تا ۳ (۵.۰.۰ تا ۵.۲.۰) باید نصب شده باشند.

---

## مرحلهٔ ۱ — پشتیبان‌گیری (حتماً!)

1. وارد **cPanel** شوید.
2. **phpMyAdmin** → پایگاه دادهٔ سایت → تب **Export** → **Go**.
3. **File Manager** → `public_html` → **Compress** → نوع **Zip**.

---

## مرحلهٔ ۲ — آپلود فایل‌های پچ

1. فایل `joma-patch-finance-stage4.zip` را از لینک مستقیم دانلود کنید.
2. cPanel → **File Manager** → `public_html` → **Upload** → zip را آپلود کنید.
3. روی zip کلیک راست → **Extract** → `public_html`.

```
public_html
├── database/
│   └── phase5_4_sales_schema.sql      ← جدید
├── includes/
│   └── finance_functions.php          ← به‌روز شده (کامل، شامل مراحل ۱+۲+۳+۴)
├── reception/
│   ├── finance_test_sales.php         ← جدید (🧪 فروشِ تست‌ها)
│   └── finance_package_sales.php      ← جدید (📦 فروشِ پکیج‌ها)
├── templates/
│   └── sidebar.php                    ← به‌روز شده (۲ منوی جدید)
└── upgrade_phase5_4.php               ← اسکریپت مهاجرت (یک‌بارمصرف)
```

> ✅ فایل‌های `includes/finance_functions.php` و `templates/sidebar.php` نسخهٔ کامل هستند و نسخهٔ قبلی را می‌پوشانند.

## مرحلهٔ ۳ — اجرای مهاجرت پایگاه داده

1. مرورگر → `https://my.mirbolouki.com/upgrade_phase5_4.php`
2. با نام کاربری **مدیر** وارد شوید.
3. دکمهٔ **🚀 اجرای مهاجرت مرحلهٔ ۴ (فروشِ تست‌ها و پکیج‌ها)** را بزنید.

> 📌 این اسکریپت دو جدولِ تازه می‌سازد: `finance_test_sales` و

## مرحلهٔ ۵ — نحوهٔ استفاده

### 🧪 فروشِ تست
1. منوی راست → **«🧪 فروشِ تست‌ها»**.
2. فرمِ «ثبت فروشِ تستِ جدید»:
   - **مراجع** را از فهرستِ کشویی انتخاب کنید (نام + موبایل).
   - **نامِ تست** را بنویسید (مثلاً «تستِ Beck»).
   - **مبلغِ فروش** را به تومان وارد کنید.
   - **وضعیتِ پرداخت** را از فهرستِ کشویی انتخاب کنید
     («در انتظارِ پرداخت» یا «پرداخت‌شده»).
   - اگر «پرداخت‌شده» انتخاب کردید، **حسابِ بانکیِ پرداخت** را هم
     از فهرستِ کشویی انتخاب کنید.
3. دکمهٔ «💾 ثبت فروش».
4. در فهرستِ پایین، برای تغییرِ وضعیت، روی «✏️ ویرایش» کلیک کنید.

> 💡 پولِ تست از **درگاهِ خودتان** می‌آید؛ سیستم فقط ثبت می‌کند.

### 📦 فروشِ پکیجِ یک‌ماهه
1. منوی راست → **«📦 فروشِ پکیج‌ها»**.
2. فرمِ «ثبت فروشِ پکیجِ جدید»:
   - **مراجع**، **نامِ پکیج** (پیش‌فرض: «بستهٔ تمرینِ یک‌ماهه»)، **مبلغ**.
   - **شروعِ اعتبار** و **پایانِ اعتبار** را با سه فهرستِ کشوییِ
     **سال / ماه / روز** انتخاب کنید (پیش‌فرض: از امروز تا یک‌ماهه بعد).
   - **وضعیتِ پرداخت** + **حسابِ بانکیِ پرداخت** (مثل بالا).
3. دکمهٔ «💾 ثبت فروش».
4. پیامِ موفقیت، بازهٔ اعتبار را نشان می‌دهد.

## ❓ اگر مشکلی پیش آمد

| مشکل | راه‌حل |
|---|---|
| خطای «پیش‌نیازها کامل نیستند» | مراحل ۱ تا ۳ نصب نیستند؛ ابتدا آن‌ها را نصب کنید. |
| «مراجع را از فهرستِ کشویی انتخاب کنید» | یعنی فهرستِ مراجعین خالی است؛ اول از صفحهٔ پذیرش مراجع را ثبت کنید. |
| «مبلغِ فروش را به تومان وارد کنید» | مبلغ را با عدد (مثلاً ۵۰۰۰۰۰) وارد کنید. |
| «برای وضعیتِ «پرداخت‌شده»، حسابِ بانکی را انتخاب کنید» | حسابِ بانکیِ پرداخت را از فهرست انتخاب کنید. |
| «تاریخِ ... نامعتبر است» | چنین روزی در آن ماه وجود ندارد (مثلاً ۳۱ اسفند). |
| «تاریخِ پایانِ اعتبار نباید قبل از تاریخِ شروع باشد» | ترتیبِ بازه را اصلاح کنید. |
| صفحه سفید / خطای 500 | `storage/logs/error_YYYY-MM-DD.log` را باز کنید؛ خط آخر را برایم بفرستید. |
