# از کجا شروع کنم؟

این بسته، **ارتقای** سامانهٔ جوما از فاز ۱ به فاز ۲ (نوبت‌دهی و تقویم) است.
یک نصب تازه نیست؛ باید فاز ۱ از قبل روی هاست نصب و فعال باشد.

## ترتیب خواندن

| گام | فایل | برای چه کسی |
|---|---|---|
| ۱ | `INSTALLATION_GUIDE_PHASE2_FA.html` | **با مرورگر باز کنید.** راهنمای گام‌به‌گام ارتقا، بدون نیاز به دانش فنی. |
| ۲ | `PHASE2_TEST_REPORT_FA.md` | فهرست آزمون‌هایی که پس از ارتقا باید انجام دهید. |
| ۳ | `PHASE2_FINAL_DECISIONS.md` | سند فنی تصمیم‌های معماری، برای برنامه‌نویس آینده. |
| ۴ | `VERSION.txt` | شمارهٔ نسخه و تاریخ ساخت. |
| ۵ | `MANIFEST.txt` | فهرست کامل فایل‌های بسته با اثر انگشت SHA-256. |

## سه نکتهٔ حیاتی

1. **پیش از هر کاری از پایگاه داده پشتیبان بگیرید.**
2. فایل `includes/config.php` و `install.lock` را روی هاست **دست نزنید**.
3. کد فاز ۲ **اجرا و آزمایش نشده است**؛ آزمون‌های سند شمارهٔ ۲ را جدی بگیرید.

## این پوشه را روی هاست نگذارید

فقط محتویات پوشهٔ `public_html` روی هاست می‌رود. پوشهٔ `مستندات` فقط برای شماست.
