# راهنمای نصب پچ «فاز ۵ — تسویه با مراکز» (مرحلهٔ ۳)

این پچ **بخش سوم** ماژول مدیریت مالی را اضافه می‌کند:

- 🤝 **تسویه با مراکز مشاوره** — برای هر «مرکز × بازهٔ زمانی» یک رکوردِ تسویه
- 🧮 **محاسبهٔ خودکار** مبلغِ قابل‌پرداخت به مرکز:
  - مرکزِ **درصدی** → درصد × مجموعِ پرداخت‌های «پرداخت‌شده»ِ جلساتِ اتاق‌های آن مرکز در بازه
  - مرکزِ **ساعتی** → مجموعِ (ساعتِ جلسه × تعرفهٔ ساعتیِ اتاق) — نوبتِ زوج/خانواده خودکار با تعرفهٔ اتاقِ زوج حساب می‌شود
- 💰 **ثبت پرداخت** به مرکز: مبلغِ واریزی (تومان) + حسابِ بانکیِ پرداخت + وضعیت (پرداخت‌نشده / جزئی / پرداخت‌شده)
- 📅 تاریخ‌های بازه به‌صورت **شمسی** وارد می‌شوند؛ پیش‌فرضِ بازه بر اساس نوعِ مرکز (ماهیانه → ماهِ جاری، روزانه → امروز) پیشنهاد می‌شود
- 📊 کارتِ خلاصه: مجموعِ قابل‌پرداخت و پرداخت‌شده

> ⚠️ **پیش‌نیاز:** مراحل ۱ و ۲ (زیرساخت + پرداختِ جلسات) باید نصب شده باشند.

---

## مرحلهٔ ۱ — پشتیبان‌گیری (حتماً!)

1. وارد **cPanel** شوید.
2. **phpMyAdmin** → پایگاه دادهٔ سایت → تب **Export** → **Go**.
3. **File Manager** → `public_html` → **Compress** → نوع **Zip**.

---

## مرحلهٔ ۲ — آپلود فایل‌های پچ

1. فایل `joma-patch-finance-stage3.zip` را از لینک مستقیم دانلود کنید.
2. cPanel → **File Manager** → `public_html` → **Upload** → zip را آپلود کنید.
3. روی zip کلیک راست → **Extract** → `public_html`.

```
public_html
├── admin/
│   └── finance_settlements.php        ← جدید (صفحهٔ تسویه با مراکز)
├── database/
│   └── phase5_3_settlements_schema.sql ← جدید
├── includes/
│   └── finance_functions.php          ← به‌روز شده (کامل، شامل مراحل ۱+۲+۳)
├── templates/
│   └── sidebar.php                    ← به‌روز شده (منوی «تسویه با مراکز»)
└── upgrade_phase5_3.php               ← اسکریپت مهاجرت (یک‌بارمصرف)
```

> ✅ فایل‌های `includes/finance_functions.php` و `templates/sidebar.php` نسخهٔ کامل هستند و نسخهٔ قبلی را می‌پوشانند.

## مرحلهٔ ۳ — اجرای مهاجرت پایگاه داده

1. مرورگر → `https://my.mirbolouki.com/upgrade_phase5_3.php`
2. با نام کاربری **مدیر** وارد شوید.
3. دکمهٔ **🚀 اجرای مهاجرت مرحلهٔ ۳ (تسویه با مراکز)** را بزنید.
4. پیام سبز **«✅ مهاجرت با موفقیت انجام شد»** باید ظاهر شود.

> 📌 این اسکریپت یک جدول تازه می‌سازد: `finance_center_settlements` — هیچ دادهٔ قدیمی را حذف/ویرایش نمی‌کند.

## مرحلهٔ ۴ — حذف اسکریپت مهاجرت

پس از پیام موفقیت، فایل `upgrade_phase5_3.php` را از `public_html` **حذف** کنید.

## مرحلهٔ ۵ — نحوهٔ استفاده

### الف) ایجاد تسویه (محاسبهٔ خودکار)
1. وارد سایت شوید (**مدیر**) → منوی راست → **«🤝 تسویه با مراکز»**.
2. در فرمِ «ایجاد تسویهٔ جدید":
   - **مرکز** را از فهرستِ کشویی انتخاب کنید (کنارش نوعِ تسویه — ماهیانه/روزانه — نوشته شده).
   - **از تاریخ** و **تا تاریخ** را به‌صورت شمسی وارد کنید (پیش‌فرض: ماهِ شمسیِ جاری؛ برای مرکزِ روزانه، هر دو تاریخ = امروز).
3. روی **«🧮 محاسبه و ثبت تسویه»** کلیک کنید.
4. سیستم محاسبه می‌کند و پیام می‌دهد مثلاً:
   *«تسویه ثبت شد. مبلغِ قابل‌پرداخت: ۴۵۰٬۰۰۰ تومان — ۱٬۵۰۰٬۰۰۰ تومان (واریزی) × ۳۰٪»*

> 🧮 **نحوهٔ محاسبه:**
> - مرکزِ **درصدی**: درصد × مجموعِ بیعانه‌ها و الباقی‌های «پرداخت‌شده»ِ جلساتِ اتاق‌های آن مرکز که **تاریخِ پرداختشان** در بازه افتاده.
> - مرکزِ **ساعتی**: مجموعِ ساعتِ جلساتِ «انجام‌شده/رزوروشده» × **تعرفهٔ ساعتیِ اتاق** (همان مبلغی که در مرحلهٔ ۱ به تومان وارد کردید). نوبت‌های لغوشده و «عدم مراجعه» حساب نمی‌شوند؛ نوبت‌های زوج/خانواده خودکار با تعرفهٔ اتاقِ زوج حساب می‌شوند.

### ب) ثبت پرداخت به مرکز
1. در فهرستِ تسویه‌ها، روی **«💰 ثبت پرداخت»**ِ همان سطر کلیک کنید.
2. **مبلغِ واریزی** به تومان + **حسابِ بانکیِ پرداخت** (از فهرستِ کشویی) را وارد کنید.
3. روی **«💾 ثبت پرداخت»** کلیک کنید.
4. وضعیت به‌روز می‌شود: «پرداخت‌نشده» 🔴 → «پرداختِ جزئی» 🟡 → «پرداخت‌شده» 🟢
   (وقتی مبلغِ واریزی ≥ مبلغِ قابل‌پرداخت شد، تاریخِ پرداخت خودکار = امروز ثبت می‌شود).

### 📊 کارتِ خلاصه (بالای صفحه)
تعدادِ تسویه‌ها + مجموعِ قابل‌پرداخت + مجموعِ پرداخت‌شده.
