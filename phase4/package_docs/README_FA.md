# بستهٔ ارتقا به فاز ۴ — جوما

این بسته سامانهٔ جوما را از فاز ۳ به **فاز ۴ (فرم‌های بالینی و پورتال مراجع)** می‌برد.

## محتویات بسته

| پوشه | توضیح |
|---|---|
| `public_html/` | فایل‌هایی که روی هاست آپلود می‌شوند |
| `مستندات/` | راهنما، گزارش آزمون و اسناد تصمیم — **این پوشه را روی وب آپلود نکنید** |

## خیلی خلاصه

۱. از پایگاه داده پشتیبان بگیرید (phpMyAdmin ← Export).
۲. محتویات `public_html/` را روی هاست جایگزین کنید.
۳. با حساب **مدیر** وارد سامانه شوید.
۴. نشانی `upgrade_phase4.php` را باز کنید و دکمهٔ ارتقا را بزنید.
۵. پاورقی را ببینید: باید «نسخهٔ ۴.۰.۰» بنویسد.
۶. پس از آن، **فایل `upgrade_phase4.php` را حذف کنید**.

راهنمای کامل: `INSTALLATION_GUIDE_PHASE4_FA.html`

## هشدار مهم

این فایل‌ها هرگز نباید جایگزین شوند:

- `includes/config.php`
- `install.lock`

## وضعیت آزمون

**هیچ‌یک از ۳۵ آزمون اجرا نشده است.** محیط ساخت این بسته PHP و MySQL ندارد.
فهرست کامل در `PHASE4_TEST_REPORT_FA.md` آمده و اجرای آن بر عهدهٔ مالک است.
