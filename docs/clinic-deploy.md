# راهنمای استقرار ماژول «مدیریت مطب» (فاز اول)

## فایل‌های جدید/تغییریافته
- `my/functions/clinic.php` — هسته ماژول (جدید)
- `my/pages/clinic_*.php` — ۱۰ صفحه (جدید): dashboard, clients, client, intake, appointments, finance, receipt, settings, import, users
- `my/assets/css/clinic.css` — استایل (جدید)
- `my/tools/seed_clinic.php` — ساخت کاربر اولیه (جدید، فقط CLI)
- تغییر جزئی: `includes/{bootstrap,store,helpers,layout}.php` ،`index.php` ،`pages/login.php`

## نصب روی هاست (ساب‌دامین my)
1. کل پوشه `my/` را روی داکیومنت‌روت ساب‌دامین آپلود کنید **به‌جز** `my/data/store.json` (داده واقعی سرور نباید بازنویسی شود).
2. دسترسی نوشتن به `my/data/` بدهید (همان دسترسی فعلی کافی است).
3. با SSH یا ترمینال هاست، از داخل پوشه سایت:
   ```
   php tools/seed_clinic.php
   ```
   خروجی نام‌کاربری/رمزهای اولیه را نشان می‌دهد.
4. وارد شوید (`index.php?p=login`) و **فوراً** رمزها را عوض کنید (صفحه کاربران مطب).
5. در «تنظیمات مطب»: نام/تماس مطب، تعرفه‌ها، حالت یادآوری (دستی/خودکار) را تنظیم کنید.
6. (اختیاری) فایل `my/tools/seed_clinic.php` را بعد از seed حذف کنید.

## نکته‌ها
- ماژول با `storage=file` کار می‌کند (همان config فعلی). حالت MySQL نیاز به مایگریشن جداگانه دارد.
- لینک پذیرش عمومی است (توکن یک‌بارمصرف ۷روزه) — نیاز به لاگین ندارد.
- داده بالینی (بخش ۲–۵، خلاصه‌ها، یادداشت خصوصی) فقط برای دکتر معالج و مدیر قابل مشاهده است؛ حتی در خروجی‌ها و رسیدها نمی‌آید.
- ورود گروهی: قالب CSV را از صفحه «ورود گروهی» دانلود کنید؛ فایل `.xlsx` ساده هم پذیرفته می‌شود.
