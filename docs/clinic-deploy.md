# استقرار «مدیریت مطب» نسخه ۲.۰ (MySQL + نصب تحت وب)

> ساب‌دامین `my` فقط مطب است. بدون shell و بدون composer؛ همه‌چیز با File Manager و مرورگر.

## ۱) پیش‌نیازهای هاست

- PHP نسخه ۷.۰ یا بالاتر (روی ۷ و ۸ تست‌شده از نظر سینتکس)
- افزونه‌های `mysqli` ،`json` ،`mbstring` ،`session` (نصب‌کننده خودش چک می‌کند و اگر چیزی کم باشد می‌گوید)
- اختیاری: `ZipArchive` + `SimpleXML` فقط برای ورود فایل اکسل xlsx (بدون آن‌ها از CSV استفاده کنید)
- یک دیتابیس MySQL خالی (ساخت جدول‌ها با نصب‌کننده است)

## ۲) ساخت دیتابیس در cPanel (قدم‌به‌قدم)

1. وارد cPanel شوید → بخش **Databases** → گزینه **MySQL Databases**.
2. در قسمت **Create New Database** یک نام انتخاب کنید (مثلاً `clinic`) و **Create Database** را بزنید.
   نام نهایی معمولاً با پیشوند اکانت ساخته می‌شود، مثل `mirbolou_clinic` — **همین نام کامل را یادداشت کنید.**
3. در قسمت **MySQL Users → Add New User** یک کاربر بسازید (مثلاً `clinicuser`) با یک **رمز قوی** (دکمه Password Generator).
   نام نهایی مثل `mirbolou_clinicuser` و رمز را یادداشت کنید.
4. در قسمت **Add User To Database**، کاربر را به دیتابیس اضافه کنید و در صفحه بعد تیک **ALL PRIVILEGES** را بزنید و ذخیره کنید.
5. تمام شد. سه چیز دارید: **نام دیتابیس، نام کاربری، رمز**. این‌ها را در مرحله نصب وارد می‌کنید.

## ۳) آپلود فایل‌ها

1. در File Manager وارد پوشه ساب‌دامین `my` شوید (معمولاً `public_html/my` یا مشابه).
2. **قبل از هر چیز بکاپ بگیرید:** از کل پوشه `my` یک فایل zip دانلود کنید و نگه دارید.
3. فایل‌های جدید/تغییرکرده را آپلود و جایگزین کنید:
   - جدید: `my/install.php` ،`my/functions/clinic_db.php` ،`my/functions/clinic.php` ،`my/pages/clinic_login.php` ،`my/pages/clinic_*.php` ،`my/assets/css/clinic.css` ،`my/config/clinic_db.example.php`
   - جایگزین: `my/index.php` ،`my/includes/layout.php` (+ سه فایل با تغییر جزئی قبلی: `helpers.php` ،`store.php` ،`pages/login.php`)
4. ⚠️ این‌ها را **هرگز** آپلود/جایگزین نکنید:
   - پوشه `my/data/` روی سرور (داده‌های قدیمی هم‌مسیر + نشست‌ها) — دست‌نخورده بماند
   - فایل `my/config/clinic_db.php` اگر از قبل روی سرور ساخته شده (بعداً در نصب ساخته می‌شود)
5. سطح دسترسی پوشه‌های `my/config` و `my/data` باید قابل نوشتن برای PHP باشد (معمولاً پیش‌فرض درست است؛ نصب‌کننده چک می‌کند).

## ۴) اجرای نصب (از مرورگر)

1. در مرورگر باز کنید: `https://my.mirbolouki.com/install.php`
2. بخش «بررسی محیط هاست» باید همه ✅ باشد. اگر ❌ بود، آن مورد را در cPanel (بخش Select PHP Version یا مشابه) فعال کنید و صفحه را رفرش کنید.
3. مشخصات دیتابیس مرحله ۲ را وارد کنید (هاست معمولاً `localhost`).
4. یک حساب **مدیر سیستم** بسازید (نام کاربری انگلیسی + رمز حداقل ۶ نویسه) و دکمه نصب را بزنید.
5. پیام «نصب با موفقیت انجام شد» که آمد:
   - ✅ **همین فایل `install.php` را از File Manager حذف کنید** (مهم امنیتی)
   - وارد شوید: `https://my.mirbolouki.com/` → صفحه ورود مطب → پیشخوان

## ۵) چک‌لیست ۱۵ دقیقه‌ای بعد از نصب

| # | تست | نتیجه موردانتظار |
|---|-----|------------------|
| ۱ | ورود با مدیر | پیشخوان مطب باز شود |
| ۲ | کاربران مطب → ساخت دکتر + منشی | هر دو در فهرست کادر |
| ۳ | پرونده‌ها → پرونده جدید | شماره پرونده `سال-۰۰۰۱` بسازد |

## ۶) کارهای روزانه مدیر (بدون کدنویسی)

- **بکاپ دیتابیس:** cPanel → phpMyAdmin → انتخاب دیتابیس → Export. هفته‌ای یک‌بار کافی است.
- **تعرفه‌ها:** تنظیمات مطب → تعرفه‌ها (بعد از نصب همه صفر‌اند؛ حتماً وارد کنید).
- **حالت یادآوری:** تنظیمات مطب → دستی/خودکار + آدرس سامانه پیامکی.

## ۷) بازگشت (Rollback)

داده‌های قدیمی هیچ‌وقت دست نمی‌خورند، پس بازگشت ساده است:

1. فایل zip بکاپ مرحله ۳ را روی سرور برگردانید (یا از گیت: برگرداندن `index.php` و `layout.php` + حذف فایل‌های جدید مطب).
2. جداول `clinic_*` در دیتابیس بمانند یا حذف شوند — به کار قدیمی ربطی ندارند.
3. نشست‌های قدیمی کاربران با ورود مجدد ساخته می‌شوند.
