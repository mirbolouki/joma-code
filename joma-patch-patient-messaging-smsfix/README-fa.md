# اصلاح ارسال پیامک پیام‌های مراجع — بدون مهاجرت جدید

این اصلاح برای پچ پیام‌رسانی فاز ۱ است. چون مهاجرت `6.2.0` را انجام داده‌اید، **مهاجرت را دوباره اجرا نکنید**. این ZIP فقط دو فایل برنامه را به‌روز می‌کند.

## نصب ساده در cPanel

1. در cPanel → **File Manager**، از این دو فایل یک کپی پشتیبان بگیرید:
   - `includes/patient_message_functions.php`
   - `admin/sms_settings.php`
2. فایل `joma-patch-patient-messaging-smsfix.zip` را دانلود و در همان پوشهٔ اصلی سایت (جایی که پوشهٔ `includes` وجود دارد) آپلود کنید.
3. روی ZIP راست‌کلیک کنید → **Extract** → مقصد را ریشهٔ برنامه انتخاب کنید. اگر پرسید، فقط همین دو فایل هم‌نام را جایگزین کنید.
4. **هیچ مهاجرتی اجرا نکنید** و فایل‌های دیگر یا `includes/config.php` را تغییر ندهید.

## بررسی پیامک در سایت

1. با حساب مدیر وارد شوید: **تنظیمات پیامک**.
2. حالت را روی **فعال — ارسال واقعی با SMS.ir** بگذارید.
3. در کارت **وضعیت تنظیمات اعلان مراجع** ببینید آیا «خط ارسال جایگزین» موجود است.
   - اگر موجود است، شناسهٔ قالب را خالی بگذارید و **آزمایش اعلان لینک ورود** را بزنید؛ برنامه از همان خطی که قبلاً در سایت تنظیم شده استفاده می‌کند.
   - اگر موجود نیست، باید قالب خدماتی Verify زیر را در SMS.ir بسازید و پس از تأیید، شناسه‌اش را در فیلد **شناسهٔ قالب پیام تازه در پورتال** وارد کنید.
4. برای پیامک خدماتی با امکان رسیدن به شماره‌هایی که پیامک تبلیغاتی را مسدود کرده‌اند، مسیر قالب Verify توصیه می‌شود؛ خط عادی ممکن است به همهٔ شماره‌ها نرسد.

## متن دقیق قالب SMS.ir

در SMS.ir به **برنامه‌نویسان → ارسال سریع → لیست قالب‌ها → افزودن قالب** بروید و این متن را ثبت کنید:

```text
کلینیک جوما: #notice# دارید؛ برای بررسی پیام وارد کلینیک شوید:
https://my.mirbolouki.com/patient_login.php
```

- نام پارامتر: `notice` (در متن به صورت `#notice#`).
- مقدار کوتاهی که برنامه می‌فرستد: `پیام جدید`.
- لینک ورود داخل متن قالب ثابت است؛ آن را به‌صورت متغیر لینک تعریف نکنید.
- پس از تأیید SMS.ir، شناسهٔ قالب را در تنظیمات پیامک سایت وارد و ذخیره کنید. قالب کد یک‌بارمصرف با `CODE` را تغییر ندهید.

چون کلید API قبلی در مخزن عمومی افشا شده، پیش از استفادهٔ واقعی آن را در پنل SMS.ir باطل و rotate کنید؛ کلید را برای کسی نفرستید. این اصلاح کلیدی را داخل ZIP ندارد و مهاجرت پایگاه‌داده را تغییر نمی‌دهد.
