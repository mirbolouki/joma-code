## ۵. معماری و امنیت

### ۵-۱. پشتهٔ فناوری
PHP 7.4+ · MySQL 5.7.20+/MariaDB · `mysqli` با Prepared Statement · بدون Composer · بدون وابستگی به mysqlnd · HTML/CSS/JS خالص · قلم Vazirmatn محلی با مجوز OFL.

### ۵-۲. تدابیر امنیتی پیاده‌شده

| تدبیر | پیاده‌سازی |
|---|---|
| ذخیرهٔ رمز عبور | bcrypt (`password_hash`) — رمز خام هرگز ذخیره نمی‌شود |
| تزریق SQL | تمام کوئری‌ها Prepared Statement |
| XSS | تمام خروجی‌ها از `htmlspecialchars` با `ENT_QUOTES` |
| CSRF | توکن ۶۴ نویسه‌ای روی تمام فرم‌ها، مقایسه با `hash_equals` |
| نشست | کوکی `HttpOnly` + `Secure`، بازتولید شناسه در لحظهٔ ورود |
| محدودسازی ورود | ۵ تلاش ناموفق در ۱۵ دقیقه → قفل موقت |
| محدودسازی کد پیامکی | ۳ درخواست در ۱۰ دقیقه برای هر شماره + فاصلهٔ ۹۰ ثانیه |
| کد یک‌بارمصرف | فقط هش ذخیره می‌شود؛ مصرف اتمیک؛ مقید به موبایل + هدف |
| افشای خطا | `display_errors=0`؛ کاربر فقط کد پیگیری می‌بیند |
| محافظت پوشه‌ها | `.htaccess` روی `includes`، `database`، `templates`، `storage/logs` |
| عدم افشای وجود حساب | پیام بازیابی رمز برای حساب موجود و ناموجود یکسان است |
| ردیابی | ۱۸ کد رویداد در `audit_log`؛ کد خام پیامک هرگز لاگ نمی‌شود |

### ۵-۳. حاکمیت داده
تمام زمان‌ها به **وقت جهانی (UTC)** ذخیره و در نمایش به **تقویم شمسی و وقت تهران** تبدیل می‌شوند. هیچ رکوردی حذف فیزیکی نمی‌شود (کلیدهای خارجی `ON DELETE RESTRICT`). شناسه‌های بیرونی (`public_id`) غیرقابل‌حدس و تصادفی‌اند.
