📘 راهنمای کامل نصب — سامانهٔ جوما، فاز ۱

این راهنما برای کسی نوشته شده که هیچ دانش برنامه‌نویسی ندارد. هیچ‌جا نیاز به ترمینال، SSH، Composer یا ویرایش کد نیست.

زمان لازم: حدود ۲۰ دقیقه.

اگر هنوز کلید SMS.ir ندارید، اشکالی ندارد: در مرحلهٔ نصب گزینهٔ «حالت آزمایشی» را انتخاب کنید و بعداً از داخل سامانه آن را فعال کنید.

گام ۱ — ساخت دیتابیس

  1. وارد cPanel شوید.
  2. در کادر جست‌وجوی بالا بنویسید MySQL و روی MySQL® Databases کلیک کنید.
  3. در بخش Create New Database یک نام بنویسید، مثلاً joma و دکمهٔ Create Database را بزنید.
  • cPanel خودش پیشوند حساب شما را اضافه می‌کند؛ نام نهایی چیزی شبیه username_joma می‌شود. این نام کامل را یادداشت کنید.
  1. پایین‌تر، در MySQL Users → Add New User:
  • نام کاربری: مثلاً jomauser
  • رمز: روی Password Generator بزنید و رمز ساخته‌شده را در جایی امن یادداشت کنید.
  • Create User را بزنید.
  1. پایین‌تر، در Add User To Database: کاربر و دیتابیسی که ساختید را انتخاب و Add را بزنید.
  2. در صفحهٔ بعد، تیک ALL PRIVILEGES را بزنید و Make Changes را کلیک کنید.

در پایان این گام باید چهار چیز را یادداشت کرده باشید:

میزبان (Host):        localhost
نام دیتابیس:          username_joma
نام کاربری دیتابیس:    username_jomauser
رمز دیتابیس:          ××××××××

گام ۲ — آپلود فایل‌ها

  1. فایل ZIP را روی کامپیوتر خود باز (Extract) کنید.
  2. در cPanel وارد File Manager شوید.
  3. وارد پوشهٔ public_html شوید.
  • اگر می‌خواهید سامانه روی خودِ دامنه باشد (https://example.com) → همین‌جا بمانید.
  • اگر می‌خواهید در زیرپوشه باشد (https://example.com/joma) → پوشه‌ای به نام joma بسازید و واردش شوید.
  1. روی Upload کلیک کنید و تمام محتویات پوشهٔ public_html بستهٔ جوما را آپلود کنید.
روش ساده‌تر و سریع‌تر: از پوشهٔ public_html بسته، یک فایل ZIP بسازید، همان یک فایل را آپلود کنید، سپس در File Manager روی آن راست‌کلیک کرده و Extract را بزنید. بعد فایل ZIP را حذف کنید.

بررسی اینکه درست آپلود شده

در File Manager باید این‌ها را ببینید: install.php، login.php، health.php و پوشه‌های admin، reception، therapist، includes، templates، assets، database، storage.

⚠️ فایل‌های .htaccess مخفی‌اند. در File Manager از منوی Settings گزینهٔ Show Hidden Files (dotfiles) را تیک بزنید تا دیده شوند. وجود این فایل‌ها برای امنیت ضروری است.

تنظیم دسترسی‌ها

روی پوشهٔ storage/logs راست‌کلیک کنید ← Change Permissions ← مقدار ۷۵۵. همین مقدار برای پوشهٔ includes هم لازم است. هرگز ۷۷۷ نگذارید.

گام ۳ — اجرای نصب‌کننده

در مرورگر، نشانی زیر را باز کنید (به‌جای نشانی نمونه، نشانی خودتان را بگذارید):

https://example.com/install.php

مرحلهٔ ۱ — اتصال دیتابیس

فرم را با همان چهار مقداری که در گام ۱ یادداشت کردید پر کنید:

فیلدمقدار
میزبان دیتابیسlocalhost
نام دیتابیسusername_joma
نام کاربری دیتابیسusername_jomauser

سپس بخش تنظیمات پیامک:

  • اگر کلید SMS.ir دارید → «ارسال واقعی با سامانهٔ SMS.ir» را انتخاب و کلید API و شناسهٔ قالب را وارد کنید.
  • اگر ندارید → «حالت آزمایشی» را انتخاب کنید.

دکمهٔ «آزمایش اتصال و ادامه» را بزنید.

اگر پیام «اتصال به دیتابیس برقرار نشد» دیدید: املای نام دیتابیس و نام کاربری را با پیشوند حساب (username_) دوباره بررسی کنید. اگر پیام «پوشهٔ includes قابل نوشتن نیست» دیدید: دکمهٔ «دانلود فایل تنظیمات آماده» را بزنید، فایل config.php دانلود‌شده را در File Manager داخل پوشهٔ includes آپلود کنید و بعد دکمهٔ «ادامه» را بزنید. (نیازی به باز کردن یا ویرایش آن فایل نیست.)

مرحلهٔ ۲ — ساخت جدول‌ها

فقط دکمهٔ «ساخت جدول‌ها» را بزنید. سامانه خودش ۱۱ جدول و داده‌های اولیه (دلیل‌های مراجعه، دلیل‌های عدم پذیرش و ۵ نوع خدمت) را می‌سازد. جدولی از نتیجه نمایش داده می‌شود.

گام ۴ — نخستین ورود

  1. به https://example.com/login.php بروید.
  2. نام کاربری و رمز مدیر را وارد کنید.
  3. سامانه شما را به صفحهٔ تغییر اجباری رمز می‌برد. رمز جدیدی انتخاب کنید.
  4. داشبورد مدیر باز می‌شود. 🎉

گام ۵ — پاک‌سازی و بررسی سلامت

  1. خودآزمون: در همان مرورگری که با حساب مدیر وارد شده‌اید، نشانی https://example.com/health.php را باز کنید. همهٔ ردیف‌ها باید سبز باشند.
  • (این صفحه برای افراد واردنشده فقط بین ساعت ۰۱:۰۰ تا ۰۲:۰۰ بامداد به وقت تهران باز می‌شود؛ این یک محدودیت امنیتی عمدی است.)
  1. در File Manager فایل install.php را حذف کنید.
  2. پس از اطمینان از سلامت، فایل health.php را هم حذف کنید.

گام ۶ — ساخت کاربران و شروع کار

  1. داشبورد مدیر ← ➕ ایجاد کاربر جدید
  2. یک منشی بسازید؛ نقش «منشی» را تیک بزنید.
  3. یک درمانگر بسازید؛ نقش «درمانگر» را تیک بزنید.
  4. پس از هر ساخت، کادر زرد نام کاربری و رمز اولیه را نشان می‌دهد. آن را یادداشت کنید — فقط همین یک‌بار نمایش داده می‌شود و حضوری به شخص تحویل دهید.
  5. حالا منشی می‌تواند از ➕ ثبت پذیرش جدید استفاده کند.

❓ مشکلات رایج

نشانهعلت و راه‌حل
«سامانه قبلاً نصب شده است»فایل install.lock وجود دارد. اگر واقعاً می‌خواهید از نو نصب کنید، باید آن فایل، فایل includes/config.php و تمام جدول‌های دیتابیس حذف شوند.
«سامانه هنوز نصب نشده است»فایل includes/config.php ساخته نشده؛ install.php را اجرا کنید.
صفحهٔ سفیدمعمولاً نسخهٔ PHP قدیمی است. در cPanel → MultiPHP Manager نسخه را روی ۷.۴ یا بالاتر بگذارید.
قلم فارسی درست نیستپوشهٔ assets/fonts کامل آپلود نشده است.
کد پیامک نمی‌آیداز صفحهٔ «تنظیمات پیامک» دکمهٔ «ارسال پیامک آزمایشی» را بزنید. اگر خطا داد، کلید API و شناسهٔ قالب را بررسی کنید. نام پارامتر قالب باید CODE باشد.
در حالت آزمایشی کد را کجا ببینم؟File Manager ← storage/logs/sms_debug.log
صفحهٔ خطا با کد REF-xxxxجزئیات فنی در storage/logs/error_تاریخ.log است؛ همان کد را به پشتیبانی بدهید.
هاست من Nginx استفایل‌های .htaccess روی Nginx کار نمی‌کنند. از پشتیبانی هاست بخواهید دسترسی مستقیم وب به پوشه‌های includes، database، templates و storage را ببندد.

🔄 به‌روزرسانی در آینده

برای فازهای بعدی، فایل‌های جدید روی فایل‌های قبلی آپلود می‌شوند؛ فایل includes/config.php شما دست‌نخورده باقی می‌ماند. پیش از هر به‌روزرسانی، از دیتابیس (cPanel → phpMyAdmin → Export) و از پوشهٔ سامانه پشتیبان بگیرید.
