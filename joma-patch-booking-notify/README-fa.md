## 🛠️ نصب — ۵ قدم

### قدم ۱ — بکاپ گرفتن (خیلی مهم!)
سی‌پنل → **File Manager** → پوشهٔ `public_html` → پوشهٔ `includes`

- روی `sms.php` راست‌کلیک → **Copy** → در نامِ جدید بنویس: `sms.php.backup` → **Save**
- روی `booking_functions.php` راست‌کلیک → **Copy** → در نامِ جدید بنویس: `booking_functions.php.backup` → **Save**

> 💾 این دو فایلِ `.backup` را نگه‌دار — اگر مشکلی پیش آمد، با همین‌ها سایت برمی‌گردد.

### قدم ۲ — آپلود پکیج
- در همان File Manager، برو به پوشهٔ `public_html` (ریشهٔ سایت)
- بالا روی **Upload** بزن
- فایل `joma-patch-booking-notify.zip` را از کامپیوترت انتخاب کن
- صبر کن تا آپلود ۱۰۰٪ شود

### قدم ۳ — استخراج (Extract)
- روی `joma-patch-booking-notify.zip` راست‌کلیک → **Extract**
- اگر پرسید کجا استخراج شود → همان `public_html` → **Extract Files**
- ✅ دو فایلِ `includes/sms.php` و `includes/booking_functions.php` خودکار جایگزینِ فایل‌های قبلی می‌شوند
- 🧹 حالا می‌توانی پاک کنی (اختیاری): خودِ zip + `README-fa.md` + `config-addition.txt`

### قدم ۴ — اضافه کردنِ شناسهٔ قالب به config
- در File Manager → `public_html/includes/config.php` را پیدا کن
- راست‌کلیک → **Edit** (ویرایشگرِ متن باز می‌شود)
- با `Ctrl+End` برو به **انتهای** فایل
- این خط را در یک خطِ جدید اضافه کن:
  ```php
  define('SMSIR_BOOKING_TEMPLATE_ID', '379736');
  ```
- بالا سمت راست → **Save Changes**

> ⚠️ اگر قبلاً خطِ مشابهی با مقدارِ خالی (`''`) اضافه کرده‌ای، همان را پاک کن و این خط را بگذار.

### قدم ۵ — تست
1. یک درخواست نوبتِ تستی ثبت کن: `https://my.mirbolouki.com/booking.php`
2. چند ثانیه صبر کن
3. پیامک باید به **09967979471** برسد 📱

## 🧪 اگر پیامک نیامد (عیب‌یابی)

1. **لاگِ پیامک:** File Manager → `public_html/storage/logs/sms_debug.log` → باز کن
   - `BOOKING NOTIFY SENT (smsir)` → ارسال شده؛ شاید Gateway چند ثانیه تأخیر داشته باشد
   - `BOOKING NOTIFY FAILED` → متنِ بعدش را برایم بفرست
2. **audit_log:** در phpMyAdmin → جدول `audit_log` → دنبال `BOOKING_NOTIFY_SENT` یا `BOOKING_NOTIFY_FAILED` بگرد
3. **کدهای خطای SMS.ir:**
   - `113` = قالب پیدا نشد → شناسهٔ قالب در config را چک کن (باید `379736` باشد)
   - `119` = پلن باید ارتقا پیدا کند → با پشتیبانی SMS.ir تماس بگیر
4. **متغیرها:** در پنل SMS.ir نامِ متغیرها را چک کن — باید دقیقاً `name`، `mobile`، `day` (حرفِ کوچک) باشند

## ⚠️ نکتهٔ امنیتیِ مهم — کلید API (فوراً)

کلید APIِ SMS.ir که این سیستم استفاده می‌کند، همان کلیدی است که در فایل
`includes/config.php` داخل ریپوی عمومیِ GitHub (پرو젝트ٔ joma-code) هست — یعنی
**عمومی است** و باید فوراً عوض شود:

1. پنل SMS.ir → «تنظیمات» → «کلید API» → **کلیدِ جدید بساز** (کلیدِ قبلی را غیرفعال کن)
2. کلیدِ جدید را در `includes/config.php` **روی هاست** بگذار (مقدار `SMSIR_API_KEY`)
3. از این به بعد، فایل `config.php` را در GitHub یا Zipِ عمومی قرار نده

> رمزِ دیتابیس و `IP_HASH_KEY` هم که در همان فایل هستند، باید عوض شوند
> (در گزارشِ کامل — `REPORT-my4.md` — توضیح داده شده است).
