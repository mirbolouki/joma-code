# راهنمای نصب پچ «فاز ۵ — گزارشِ مالی» (مرحلهٔ ۵ — آخرین مرحله)

این پچ **آخرین بخش** ماژول مدیریت مالی است — یک صفحهٔ گزارشِ مالی:

- 📊 **گزارشِ مالی** (فقط مدیر) — خلاصهٔ یک بازهٔ زمانی:
  - **کلِ درآمدِ بازه** = پرداختِ جلسات + فروشِ تست + فروشِ پکیج (فقط «پرداخت‌شده»‌ها)
  - **بدهیِ مراکز** در بازه: قابل‌پرداخت / پرداخت‌شده / باقی‌مانده (به تفکیکِ مرکز)
  - **خالصِ بازه** = کلِ درآمد − بدهیِ قابل‌پرداختِ مراکز
- 📅 **فیلترِ بازه** با انتخابگرِ سه‌بخشیِ **سال / ماه / روز** (بدون تایپ) —
  پیش‌فرض: ماهِ شمسیِ جاری؛ ماه با عدد و نام نمایش داده می‌شود
- 👁️ فقط خواندنی — **هیچ تغییری در پایگاه داده نمی‌دهد** و **نیازی به مهاجرت ندارد**
- 🧰 ابزارِ مشترکِ انتخابِ تاریخ برای یکسان‌سازیِ فهرست‌های مالی با قالبِ سراسری

> ⚠️ **پیش‌نیاز:** مراحل ۱ تا ۴ نصب شده باشند.

---

## مرحلهٔ ۱ — پشتیبان‌گیری (حتماً!)

cPanel → **phpMyAdmin** → پایگاه دادهٔ سایت → تب **Export** → **Go**
(گزارشِ مالی تغییری در داده‌ها نمی‌دهد، ولی پشتیبان‌گیری همیشه عاقلانه است.)

---

## مرحلهٔ ۲ — آپلود فایل‌های پچ

1. فایل `joma-patch-finance-stage5.zip` را از لینک مستقیم دانلود کنید.
2. cPanel → **File Manager** → `public_html` → **Upload** → zip را آپلود کنید.
3. روی zip کلیک راست → **Extract** → `public_html`.

```
public_html
├── admin/
│   └── finance_report.php             ← جدید (📊 گزارشِ مالی)
├── includes/
│   ├── finance_functions.php          ← به‌روز شده (کامل، شامل مراحل ۱+۲+۳+۴+۵)
│   └── schedule_time.php              ← به‌روز شده (ابزارِ مشترکِ انتخابِ تاریخ)
└── templates/
    └── sidebar.php                    ← به‌روز شده (منوی «گزارشِ مالی»)
```

> ✅ فایل‌های `includes/finance_functions.php`، `includes/schedule_time.php` و `templates/sidebar.php` نسخهٔ کامل هستند و نسخهٔ قبلی را می‌پوشانند.

## مرحلهٔ ۴ — نحوهٔ استفاده

1. وارد سایت شوید (**مدیر**) → منوی راست → **«📊 گزارشِ مالی»**.
2. در کارتِ «بازهٔ گزارش»، **از تاریخ** و **تا تاریخ** را با سه فهرستِ کشوییِ
   **سال / ماه / روز** انتخاب کنید (پیش‌فرض: ماهِ شمسیِ جاری).
3. دکمهٔ «اعمال فیلتر» را بزنید.

### صفحه چه نشان می‌دهد

| بخش | یعنی |
|---|---|
| **کلِ درآمدِ بازه** | مجموعِ بیعانه‌ها و الباقی‌های «پرداخت‌شده»ِ جلسات + فروش‌های «پرداخت‌شده»ِ تست و پکیج که تاریخِ پرداختشان در بازه است |
| **بدهیِ مراکز (قابل‌پرداخت)** | مجموعِ مبالغِ قابل‌پرداختِ تسویه‌هایی که بازه‌شان با بازهٔ گزارش هم‌پوشانی دارد |
| **پرداخت‌شده به مراکز** | مجموعِ مبالغِ واقعاً پرداخت‌شده به مراکز در آن تسویه‌ها |
| **خالصِ بازه** | کلِ درآمد − بدهیِ قابل‌پرداختِ مراکز (یعنی پس از تسویهٔ کاملِ بدهی‌ها چه مبلغی می‌ماند) |

جدولِ «درآمد بر اساسِ منبع» — تفکیکِ «جلسات»، «تست‌ها»، «پکیج‌ها» + جمع؛ ستونِ «در انتظار» = وضعیتِ فعلی (مستقل از بازه).

جدولِ «تسویه با مراکز در بازه» — به تفکیکِ مرکز: مدل (درصدی/ساعتی)، تعداد، قابل‌پرداخت، پرداخت‌شده، باقی‌مانده + جمع.
